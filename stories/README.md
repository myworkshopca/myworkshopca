## Code for TEJ3

This is a *private* repository, as Jessica preferred.

```bash
# set the working folder for the git repo.
cd ~/rd; ls -la
cd ~/rd; git clone git@github.com:myworkshopca/tej3.git
```

Start working on it by using vim editor command
```vim
vert new ~/rd/tej3/
```

Create a copy of the file *tej3/ISP/buttonv2.ino* to work on it
```bash
cd ~/rd/tej3/ISP; ls -la
cd ~/rd/tej3/ISP; cp -v buttonv2.ino buttonv2-sean.ino
```
